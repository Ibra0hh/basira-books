# البصيرة

موقع عربي لقراءة سلسلة «البصيرة». ترتيب الكتب: **الكاتب، الرسول، العالم، المهندس**.

النسخة الحالية تبدأ بمخطط «الكاتب»: خمسة أجزاء وعشرون فصلًا. لا تُعرض محاور الفصول أو الأسئلة التحضيرية بوصفها سيرة مكتوبة. تُضاف النصوص بعد مشاركة المؤلف مادته ومراجعة الصياغة.

## التشغيل محليًا

المطلوب: Node.js 20 أو أحدث وPython 3.10 أو أحدث. لا توجد حزم خارجية يجب تثبيتها.

```sh
npm run check
npm run build
npm run preview
```

افتح `http://localhost:4173`. إذا كان اسم Python في جهازك هو `python3` فشغّل المعاينة بالأمر `python3 -m http.server 4173 --directory docs`.

يمكن تعيين متغير البيئة `PYTHON` إلى المسار الكامل لمفسّر Python عند البناء. يكتشف البناء تلقائيًا أوامر `python` و`python3` و`py -3` حسب نظام التشغيل.

## تحرير الكتاب

المصدر المعتمد للمحتوى هو `content/books.json`. ملفات `docs/data/books.json` و`docs/downloads/alkatib.*` مشتقة منه، فلا تُحرّرها يدويًا.

1. احتفظ بمعرّفات الكتب والأجزاء والفصول ثابتة حتى تبقى روابط القراءة صالحة.
2. اكتب اسم الغلاف المعتمد في `series.author`. يبقى `null` حتى يحدد المؤلف الاسم الذي يريده.
3. حدّث `series.updatedAt` عند إصدار تعديل، بصيغة UTC مثل `2026-11-02T12:00:00Z`. إن لم يوجد الحقل، يستخدم التصدير تاريخ الإصدار الأول `2026-11-02T00:00:00Z`.
4. أضف السرد المعتمد إلى `paragraphs` بوصفه مصفوفة فقرات نصية، وغيّر حالة الفصل من `outline` إلى `draft`. تستخدم `review` للمسودة قيد المراجعة، و`published` للنص الجاهز.
5. تبقى `outline` محاور تحريرية، و`prompts` أسئلة تحضيرية. ملفات الكتاب القابلة للتنزيل لا تتضمن الأسئلة التحضيرية، وتوسم الفصول غير المكتوبة بوضوح.
6. شغّل `npm run check` ثم `npm run build`، وافحص الموقع والتنزيلات، ثم ارفع التغييرات وملفات البناء المولّدة معًا.

المحتوى نص عادي؛ يتولى العرض والتصدير التعامل مع أحرف HTML. لا تضع أسرارًا أو معلومات غير مخصّصة للنشر في ملف المحتوى العام أو سجل Git.

## الملفات والتنزيلات

- `content/books.json`: بيانات السلسلة والمحتوى ومخطط الفصول.
- `docs/`: الموقع الجاهز للنشر، بما فيه ملفات الواجهة والأصول.
- `docs/data/books.json`: نسخة المحتوى التي يقرأها الموقع.
- `docs/downloads/alkatib.epub`: كتاب EPUB 3 عربي، بفهرس كامل واتجاه تقليب صفحات من اليمين إلى اليسار.
- `docs/downloads/alkatib.md`: نسخة نصية قابلة للتحرير بصيغة Markdown.
- `docs/downloads/alkatib.html`: نسخة مستقلة قابلة للقراءة دون اتصال والطباعة أو الحفظ بصيغة PDF من المتصفح.
- `scripts/build.mjs`: التحقق من البيانات وJavaScript، ونسخ المحتوى، وتشغيل التصدير.
- `scripts/export_book.py`: إنشاء ملفات الكتاب وفحص حاوية EPUB وXML والفهرس والروابط.

يُضمّن غلاف `docs/assets/alkatib-cover.png` والخطوط المحلية المتاحة من عائلتي Amiri وNoto Sans Arabic في نسختي EPUB وHTML. ملفاتهما اختيارية؛ تبقى التنزيلات قابلة للإنشاء دونها. راجع تراخيص الخطوط الموجودة بجانبها قبل تغيير ملفات الخطوط.

لا يمس البناء ملفات الواجهة أو الأصول. يعيد كتابة البيانات والتنزيلات المعروفة فقط. عند ثبات المحتوى والأصول والتاريخ، ينتج الملفات نفسها. يمكن ضبط `SOURCE_DATE_EPOCH` لتوحيد تاريخ EPUB في أنظمة البناء القابلة لإعادة الإنتاج.

## النشر على GitHub Pages

المسار المقصود للموقع: `https://ibra0hh.github.io/basira-books/`.

إعداد Pages هو **Deploy from a branch → main → /docs**. يجب إبقاء `docs/.nojekyll` وملفات الموقع الناتجة في Git. بعد كل تحديث للمحتوى يُنفّذ البناء محليًا وتُرفع مخرجاته مع المصدر؛ لا توجد خدمة خلفية أو مرحلة بناء مخصصة على الخادم.

يجب أن يبقى هذا المشروع في مستودع Git الخاص به عند وضعه داخل مجلد عمل أكبر. تأكد من الجذر باستخدام `git rev-parse --show-toplevel` قبل الرفع.

## التحقق

`npm run check` يراجع ترتيب الكتب، الأجزاء الخمسة، الفصول العشرين، تفرد المعرّفات، ترابط الأجزاء، حالات الكتابة، وسلامة JavaScript. يرفض وضع نص سردي داخل فصل حالته `outline`، كما يرفض وسم فصل فارغ بوصفه مكتوبًا.

`npm run build` يضيف فحوصات EPUB: ترتيب ملف `mimetype` دون ضغط، سلامة ZIP وXML، البيانات العربية، اتجاه RTL، الفهرس الكامل، ترتيب القراءة، ووجود الموارد المرتبطة. هذه فحوصات موجهة وليست بديلًا عن أداة EPUBCheck الكاملة عند تجهيز طبعة نهائية.

مراجع الصيغ والنشر: [مواصفة EPUB 3.3](https://www.w3.org/TR/epub-33/)، [مصدر نشر GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
